## Почему Panda

Panda неторопливая и ничего от вас не требует. Открыли, написали, закрыли. Аккаунт не нужен, синхронизировать нечего, облака нет. Заметки лежат в папке, которую вы выбрали сами, обычными `.md`-файлами. Их можно открыть любым редактором, положить в git или скопировать на флешку.

## Что умеет

**Пишет красиво.** Редактор показывает Markdown сразу оформленным: заголовки, списки, чек-листы, цитаты, код, ссылки, картинки и вложения. На диск всё равно сохраняется чистый Markdown.

**Раскладывает по полочкам.** Вложенные папки со своими иконками, избранное, перетаскивание заметок и папок мышкой. Сортировка по дате изменения, дате создания или названию.

**Находит мгновенно.** Полнотекстовый поиск по всем заметкам работает локально и без задержек.

**Хранит секреты.** Любую заметку можно зашифровать отдельным паролем, вложения шифруются вместе с ней. Ключ при желании запоминается в Связке ключей этого Mac. Если снять шифрование, заметка снова станет обычным файлом.

**Не теряет текст.** Автосохранение (или ⌘S, если вы любите сами). Если файл изменили снаружи, Panda остановится и спросит, какую версию оставить.

**Отпускает, когда нужно.** Импорт Markdown-файлов и целых папок, экспорт заметки, папки или всего сразу. Резервная копия одним zip-архивом.

**Выглядит как дома.** Нативное меню macOS, светлая и тёмная тема, настройки шрифта, ширины редактора и плотности списка. Интерфейс на русском и английском.

## Горячие клавиши

| | |
|---|---|
| ⌘N | Новая заметка |
| ⇧⌘N | Новая папка |
| ⌥⌘N | Новая зашифрованная заметка |
| ⌘S | Сохранить |
| ⌘\\ | Показать или скрыть боковую панель |
| ⌘, | Настройки |

## Где лежат заметки

```
Panda/
├── Notes/          заметки: .md и зашифрованные .md.enc
├── Folders/        дерево папок
├── Attachments/    вложения
├── Database/       поисковый индекс, пересобирается сам
├── Backups/        резервные копии
└── Config/         настройки
```

Удалите индекс, и Panda построит его заново. Ваши заметки — это только файлы в `Notes/`.

## Установка

1. Скачайте `.dmg` из [последнего релиза](https://github.com/uonick/panda/releases/latest).
2. Перетащите приложение в «Программы».
3. Откройте. Сборка подписана и заверена Apple, никаких предупреждений не будет.
