<h1 align="center">Panda</h1>

<p align="center">

## Что умеет

- **Пишете как в обычном редакторе, а на диске остаётся `.md`.** Заголовки, списки, чек-листы, цитаты, код, ссылки. Привычные `# ` или `- [ ] ` срабатывают прямо при наборе.
- **Картинки и файлы.** Вставляются в заметку и хранятся рядом с ней.
- **Порядок.** Вложенные папки со своими иконками, избранное, теги через `#слово`, перетаскивание.
- **Поиск.** Быстрый, по тексту всех заметок, работает без интернета.
- **Пароль на отдельную заметку.** Шифрование XChaCha20-Poly1305 с ключом из пароля через Argon2id. Открытые заметки сами блокируются после бездействия. Ключ можно запомнить в Связке ключей, чтобы не вводить пароль каждый раз.
- **Переезд из Apple Notes.** Заметки из всех аккаунтов переносятся вместе с папками и картинками. Запароленные и недавно удалённые остаются на месте.
- **Импорт и экспорт Markdown.** Файлы или целая папка со структурой, обратно так же. Плюс резервная копия в один zip и восстановление из неё.
- **Если файл поменяли снаружи**, Panda не перезапишет его молча и спросит, какую версию оставить.
- **Свой вид.** Светлая, тёмная или системная тема, несколько палитр, акцентный цвет (можно как в macOS). Интерфейс на русском и английском.
- **Обновления приходят сами.** Panda проверяет их при запуске.

Заметки хранятся в выбранной папке обычными файлами. Открыть их можно чем угодно, и без Panda тоже.

## Горячие клавиши

| | |
|---|---|
| ⌘N | Новая заметка |
| ⌥⌘N | Новая зашифрованная заметка |
| ⇧⌘N | Новая папка |
| ⌘S | Сохранить |
| ⌘F | Поиск |
| ⇧⌘F | В избранное |
| ⌘L / ⇧⌘L | Заблокировать заметку / все заметки |
| ⌘O | Импорт Markdown |
| ⌘E / ⇧⌘E | Экспорт заметки / всех заметок |
| ⌘1 / ⌘2 | Все заметки / Избранное |
| ⌘\\ | Боковая панель |
| ⌘, | Настройки |

## Установка

Скачайте `.dmg` из [последнего релиза](https://github.com/uonick/panda/releases/latest) и перетащите Panda в «Программы».
