## Что умеет

- **Markdown сразу оформленным.** Заголовки, списки, чек-листы, код, ссылки, картинки, вложения. На диске остаётся чистый `.md`.
- **Папки и поиск.** Вложенные папки с иконками, избранное, перетаскивание, мгновенный локальный поиск.
- **Шифрование.** Отдельный пароль на любую заметку, ключ можно запомнить в Связке ключей.
- **Автосохранение.** Если файл изменили снаружи, Panda спросит, какую версию оставить.
- **Импорт, экспорт, резервные копии** одним zip.
- **Нативный вид.** Меню macOS, светлая и тёмная темы, русский и английский.

Аккаунта и облака нет: заметки лежат в `Notes/` обычными файлами.

## Горячие клавиши

| | |
|---|---|
| ⌘N | Новая заметка |
| ⇧⌘N | Новая папка |
| ⌥⌘N | Новая зашифрованная заметка |
| ⌘S | Сохранить |
| ⌘\\ | Боковая панель |
| ⌘, | Настройки |

## Установка

Скачайте `.dmg` из [последнего релиза](https://github.com/uonick/panda/releases/latest) и перетащите приложение в «Программы». Сборка подписана и заверена Apple.
